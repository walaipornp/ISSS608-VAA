Exploration page

1. Customer Overview

Step 1: Select X-axis data Type ( Categorical or Numerical )

Step 2: User must choose which X variable to be analyze ( The shown variable will depend on the data type that user choose)

Step 3: Select Y-axis data Type ( Categorical or Numerical )

Step 4: User must choose which Y variable to be analyze ( The shown variable will depend on the data type that user choose)

Step 5: User click update plot

Output Result

The result is depending on whether th chosen variables are numerical or categorical

2. Transaction Behavior

Step 1: Select customer lifetime value ( Gold, Platinum, Silver, Bronze )

Step 2: Select transaction ( Transfer, Withdrawal , Payment, Deposit )

Step 3: User can choose transaction period

Output Result

The result will show transaction count in line chart and transaction amount in dash line chart.

3. Churn Analysis

Step 1: User must choose which X variable to be analyze

Step 2: Select statistical test ( Parametric, Nonparametric, Robust, Bayes )

Step 3: Select confident level ( 95%, 99% )

Step 4: Select display type ( Count, Percent )

Step 5: User click update plot

Output Result

The result will be divided into 2 tabs which are Statistical Test and VCD Mosaic. The graph shows statistical relationship between churn probability and the variable that user choose.

Statistical Test VCD Mosaic

Predictive model page

1. Decision tree

Step 1: User must choose at least 2 variables and up to 45 variables to be analyze in the model

Step 2: User set model parameter

The table below details parameters that can be adjusted to tune the decision tree model.

Model Parameter Parameter Description
Controls how the dataset is divided into training and testing sets. For example, 0.8 means 80% of the data is used for training and 20% for testing.
Defines the minimum number of observations required in a node before the tree can split.
Sets the maximum number of levels the tree can grow. Deeper trees are more flexible but may overfit.
Controls whether a split is worthwhile. Higher CP makes the tree simpler, lower CP allows more splits.

Step 3: User click build model

Output Result

The result will show model performance and model visulisation.

The Model visulisation will be divided into 4 tabs which are Decision Tree, Predicted vs Actual, Feature Importance, and Scenario Prediction.
